# Triagix Website

Official website for [Triagix](https://triagix.ai) — AI-powered triage and routing for telehealth contact centers.

**Route the Right Care. Every Contact. Every Time.**

## Local Development

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → Import Project → Select repo
3. Framework: **Vite** (auto-detected)
4. Click **Deploy**
5. Add custom domain `triagix.ai` in Vercel → Settings → Domains

## Build

```bash
npm run build   # outputs to /dist
npm run preview # preview production build locally
```

## Stack

- React 18
- Vite 5
- Pure inline styles (no CSS-in-JS library needed)
- Google Fonts: Syne · DM Sans · JetBrains Mono
